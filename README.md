Custom ESP32-S3 Microcontroller

So I was originally deciding to make a FPGA board but instead I decided to make a microcontroller that I can use in the future for my other projects.
I used a lot of tutorials so I'm pretty confident it will work. I decided to use this chip because it's strong and cheap. 

Features
The board it self has it so you can charge batteries, it has a crystal clock, an antenna, and a USB-C. I didn't want it to be micro because in this day and age almost everything is micro.

The process:
I made it all in kicad, the espressif team gives very good documentation on how to make a microcontroller with their chips so it wasn't that bad. I followed this youtube tutorial (https://www.youtube.com/watch?v=EdEwRXiQsfc) and it was really useful 

Some costs:
PCB: ~$20
parts: about $42

I don't know whether I am going to solder it myself or use PCBA because if I solder it myself it is very prone to errors.
